## 范围与约束

### In Scope

1. 当前检出源码版本的模型族、训练页面、引擎、网络模块、全量/参数高效训练模式、配置字段和 feature flag 盘点。
2. 训练方向分类：角色、画风、单物体/道具、服装、姿态、表情、人物/物体特征、概念、修正/增强、slider/概念擦除或抑制，以及源码/官方资料确认的其他方向。
3. 跨模型知识：数据准备、caption/tag、触发词、正则化、bucket、分辨率、重复/步数、学习率、optimizer/scheduler、rank/alpha、缓存/精度、采样评测、过拟合、故障、复现与发布。
4. 基于官方资料和 Civitai 结构化样本的参数分布与可用性研究。
5. 候选知识、模板、评测、来源登记、覆盖矩阵和迁移清单的生成与验证。

### Out of Scope

1. 修改训练器代码、schema、validator、插件代码或现有正式资产。
2. 执行长时 GPU 训练、下载完整底模/LoRA 权重、生成图片或比较成图质量。
3. 把 Civitai 下载量、评分或单一热门模型当作推荐参数的充分证据。
4. 未经授权向正式知识库、模板库、vendored 快照、远程仓库或 release 迁移/推送/发布。
5. 为训练器当前不支持的模型族伪造可用模板；可记录差距，但不得冒充支持。

## 阶段解锁规则

1. Stage 0 未完成前不得用 README 猜测完整支持面，也不得开始批量模板采样。
