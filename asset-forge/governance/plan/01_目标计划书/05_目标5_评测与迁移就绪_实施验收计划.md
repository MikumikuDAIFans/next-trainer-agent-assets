# 目标5：评测与迁移就绪实施验收计划

## 目标

对全部候选资产执行结构、来源、覆盖、语义、validator、安全和迁移差异审查，形成一套可以提交给用户批准、但尚未执行迁移的批次包。

## 范围

- In scope: `06_评测与校验` 和 `07_迁移包` 的评测、报告、manifest、hash、目标映射、计数草案。
- Out of scope: 实际复制到正式仓库、sync、commit、push、打包、release。

## 前置条件

1. G1..G4 完成门通过。
2. 所有候选文件已冻结为审查批次。

## 验收标准

1. 每个候选知识/模板至少有一个 eval ID；关键参数、兼容冲突、未知拒答和引用真实性有专门场景。
2. 结构/lint、来源完整性、覆盖矩阵、TOML/validator、敏感信息、链接和命名检查全部执行并保留失败样本。
3. 生成 `07_迁移包/migration-manifest.json`：源、目标、操作类型、hash、版本策略、对应 eval、compat 计数变化。
4. 生成只读 `migration-preview.md`，明确新增/替换/版本化文件名；遵守“播种只补缺失”。
5. 正式 `agent-assets` 和 project Git 状态与任务开始基线相比没有由本任务造成的修改。
6. 最终 readiness 报告逐项列出 pass/fail/not-run/not-applicable 和残余风险，结论只能是 `awaiting-user-approval` 或 `not-ready`。

## 测试要求

| 类型 | 要求 | 不适用说明 |
|---|---|---|
| Unit | manifest/hash/count/schema/lint 检查 | |
| Contract | 候选路径与正式资产规则、compat/eval 计数契约 | |
| Integration | 候选→评测→manifest→迁移预览完整链路 | |
| Gray | 候选与现有正式资产 diff；README 声明与最终矩阵差异复核 | |
| Real | 宿主 validator、代表性 Agent/人工回放 | 不做 GPU 训练 |
| Zero-Short | 在新的空临时目录按 manifest 复制候选并重新全量校验 | 不复制到正式目标 |

## 证据要求

最终测试报告、失败清单、coverage、validator、hash manifest、敏感信息扫描、Git 状态和迁移预览。

## 完成门

无未授权 P0/P1；所有硬验证为 pass；未运行项透明；正式仓库未改；最终状态为 `awaiting-user-approval`。

## 对后续阶段的解锁条件

本计划不自动解锁正式迁移。只有用户审阅 readiness 和 migration preview 后给出明确批准，才可开启独立迁移变更记录。

## 残余风险

无 GPU 实训意味着模板效果仍需用户未来真实训练验证；这一边界不能在迁移时被省略。
