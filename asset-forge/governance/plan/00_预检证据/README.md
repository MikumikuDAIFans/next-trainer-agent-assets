# 预检证据与治理

本目录定义整项制备工作的证据、失败、完成门、清理、授权和变更控制规则。执行产物统一归档到：

`E:\OpenSourceTeamWork\AgentAssets\06_评测与校验\evidence`

## 文件

- `preflight-source-review.md`：事实基线与边界。
- `gate-validation-checklist.md`：GATE-00..14 状态。
- `testing-and-evidence-governance.md`：测试与证据规则。
- `risk-and-authorization-governance.md`：风险及用户授权边界。
- `change-control-governance.md`：计划变更和反漂移。
- `failure-report-template.md`：失败记录模板。
- `stage-completion-gate-template.md`：阶段完成门模板。
- `evidence-cleanup-report-template.md`：证据清理模板。
- `feasibility-probe-report-template.md`：最小可行性验证报告模板。

所有报告必须区分 `pass`、`pass-with-boundary`、`fail`、`not-run`、`not-applicable` 和 `blocked`，不得把未运行写成通过。
