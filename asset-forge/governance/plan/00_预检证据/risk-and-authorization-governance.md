# 风险与授权治理

## 风险等级

- P0：越权修改/迁移正式资产、泄漏凭据或隐私、破坏正式仓库。
- P1：错误宣称训练支持、不可导入模板、无来源参数、绕过 validator、无边界大文件下载。
- P2：外部 API 不完整/限流、样本偏差、少量链接失效、覆盖矩阵缺口。
- P3：措辞、排序、检索别名或低风险可维护性问题。

## 已授权范围

1. 只读检查当前训练器、现有正式资产和公开互联网来源。
2. 在 `E:\OpenSourceTeamWork\AgentAssets` 创建计划、脚本、原始/归一化元数据、候选知识、候选模板、评测和报告。
3. 对公开 Civitai API/页面执行受限读取请求。
4. 对暂存候选执行本地解析、lint、宿主 validator 和只读差异检查。

## 必须另行授权

1. 向正式 `agent-assets/assets/knowledge`、`assets/templates`、`assets/eval` 或 `compat.json` 写入。
2. 运行会修改主项目 vendored 快照的同步脚本。
3. commit、push、PR、release、插件打包或发布。
4. 下载完整模型权重、使用账号/token、付费 API、GPU 训练或大规模爬取。
5. 删除用户已有文件或覆盖同名正式资产。

## 授权前置材料

正式迁移请求必须同时给出：候选文件清单、目标路径、diff/新增说明、validator 结果、评测结果、compat/eval 计数变化、播种文件名策略、残余风险和回滚方法。

## 阻断规则

发现 P0 立即停止相关动作；P1 必须修复或取得明确边界授权。P2 可继续调查但不得隐藏，P3 进入维护清单。
