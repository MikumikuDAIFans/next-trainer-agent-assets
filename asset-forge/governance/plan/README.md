# Next Trainer 知识库与模板库全量制备计划

本计划以“先调查、再制备、后审查、最后由用户批准迁移”为主线。执行期间只允许写入 `E:\OpenSourceTeamWork\AgentAssets`。

## 固定阶段

1. Stage 0：训练器能力盘点
2. Stage 1：来源与 Civitai 证据采集
3. Stage 2：知识库候选编制
4. Stage 3：模板库候选编制
5. Stage 4：评测审查与迁移包
6. Stage 5：外部渠道扩展与增量资产
7. Stage 6：多轮外部渠道全量采集
8. Stage 7：广泛外部渠道与知识模板扩充

## 状态词

- 计划状态：`drafting`、`approved for execution`、`executing`、`blocked`、`complete`
- 阶段状态：`pending`、`in progress`、`done`、`blocked`
- 门禁状态：`pass`、`pass-with-boundary`、`fail`、`not-applicable`

制备完成不等于已迁移。Stage 4 的完成结果只能是“候选资产已具备迁移审查条件”；正式迁移必须等待用户另行明确授权。
